# История изменений

## 1.0.0
- Первый релиз легковесного Syslog-сервера для Home Assistant на Go.
- Сетевой приемник UDP (порт 514) с поддержкой RFC 3164 и RFC 5424.
- Высокопроизводительное хранилище SQLite WAL с буферизацией в ОЗУ для защиты накопителя.
- Автоматическая ротация по сроку давности и максимальному размеру базы.
- Встроенный веб-интерфейс в Home Assistant Ingress с live-стримингом (SSE), фильтрацией и экспортом (CSV / RAW).
- Механизмы защиты: IP Allowlist, Rate Limiting и валидация размера пакетов.
- Графический интерфейс конфигурации с русской и английской локализацией.
