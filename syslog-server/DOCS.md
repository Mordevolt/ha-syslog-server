# Документация Syslog Server для Home Assistant

## Описание
**Syslog Server** — это сверхлегковесный сервер приема и анализа системных логов с Wi-Fi роутеров, точек доступа и других сетевых устройств, работающий внутри Home Assistant как изолированное дополнение (Add-on).

## Особенности
- **Минимальное потребление ресурсов:** занимает всего ~12-15 МБ оперативной памяти и 0% CPU.
- **Полная изоляция от базы Home Assistant:** логи роутера не засоряют базу данных умного дома `home-assistant_v2.db` и не изнашивают накопитель.
- **Встроенный веб-интерфейс (Ingress):** открывается прямо в боковом меню Home Assistant с поддержкой авторизации и SSL.
- **Live Stream:** наблюдение за логами в реальном времени через Server-Sent Events (SSE).
- **Многоуровневая безопасность:**
  - Белый список IP-адресов (IP Allowlist / CIDR).
  - Защита от флуда (Rate Limiting).
  - Ограничение размера пакета.
  - Веб-интерфейс скрыт внутри Docker и не публикует внешних веб-портов.
- **Автоматическая ротация:** очистка логов старше заданного количества дней и жесткий контроль максимального размера базы данных.
- **Экспорт данных:** мгновенная выгрузка отфильтрованных логов в CSV или сырой текстовый файл (RAW).

## Настройка роутера для отправки логов

В настройках вашего роутера перейдите в раздел системного журнала / Syslog и укажите:
* **IP-адрес сервера логов:** IP-адрес вашего сервера Home Assistant (например, `192.168.1.100`).
* **Порт:** `514` (протокол UDP).
* **Уровень детализации:** `Info` или `Debug`.

### Примеры для популярных роутеров:
* **Keenetic:** Управление -> Журнал -> Отправлять на сервер Syslog -> Включить -> IP: `IP_HomeAssistant`, Порт: `514`.
* **MikroTik RouterOS:** System -> Logging -> Actions -> Добавить action с type: `remote`, remote-address: `IP_HomeAssistant`, remote-port: `514`. Затем в Rules добавить правило.
* **OpenWrt:** System -> System -> Logging -> External system log server: `IP_HomeAssistant`, External system log server port: `514`.
* **Asus / Keenetic / TP-Link:** Раздел «Системный журнал» / «Удаленный сервер syslog».

## Настройка параметров аддона в Home Assistant

Во вкладке «Конфигурация» доступны следующие параметры:

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `syslog_port` | `514` | UDP-порт для приема логов. |
| `retention_days` | `14` | Количество дней хранения логов в базе. |
| `max_db_size_mb` | `500` | Предельный размер файла базы данных SQLite (МБ). |
| `rate_limit_per_sec` | `100` | Максимум сообщений в секунду с одного IP-адреса. |
| `allowed_hosts` | `[]` | Список разрешенных IP или подсетей (например: `192.168.1.1`, `192.168.1.0/24`). Если пусто — разрешены все устройства. |
