# Home Assistant Syslog Server Add-on

[![Home Assistant](https://img.shields.io/badge/Home%20Assistant-Add--on-blue.svg)](https://www.home-assistant.io/)
[![Go](https://img.shields.io/badge/Language-Go%201.22-00ADD8.svg)](https://golang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Сверхлегковесный и безопасный **Syslog Server** для Home Assistant, созданный специально для сбора, фильтрации и анализа системных логов с Wi-Fi роутеров (Keenetic, MikroTik, OpenWrt, Asus и др.) и сетевого оборудования.

---

## 🌟 Ключевые преимущества

- ⚡ **Ультранизкое потребление ресурсов:** всего **~4–12 МБ RAM** и практически **0% CPU** (написан на чистом Go).
- 🛡️ **Защита базы данных Home Assistant:** логи роутера хранятся в изолированной базе SQLite с режимом WAL и батчингом в памяти, не изнашивая диск и не раздувая `home-assistant_v2.db`.
- 🌐 **Встроенный интерфейс Ingress:** открывается прямо в боковом меню Home Assistant под единой авторизацией и SSL без необходимости открывать дополнительные веб-порты.
- 🔴 **Live Stream в реальном времени:** отслеживание событий Wi-Fi (роуминг 802.11k/v/r, подключение клиентов, ошибки, DHCP) на лету через Server-Sent Events (SSE).
- 🔒 **Многоуровневая безопасность:**
  - Белый список IP-адресов роутеров (IP Allowlist / CIDR).
  - Защита от флуда (Rate Limiting).
  - Ограничение размера пакета (до 4 КБ).
- 🧹 **Автоматическая ротация (Retention):** удаление логов старше заданного количества дней (`retention_days`) и жесткий контроль максимального размера базы (`max_db_size_mb`).
- 📊 **Экспорт и выгрузка:** скачивание отфильтрованных логов в один клик в форматах **CSV** или **RAW TXT**.
- ⚙️ **Графическая настройка:** вкладка «Конфигурация» с готовыми подсказками на русском языке прямо в интерфейсе Home Assistant.

## 🚀 Установка в Home Assistant

1. Откройте интерфейс Home Assistant.
2. Перейдите в **Настройки** -> **Дополнения** -> **Магазин дополнений** (кнопка в правом нижнем углу).
3. Нажмите на **три точки в правом верхнем углу** и выберите пункт **Репозитории**.
4. Вставьте ссылку на этот репозиторий:
   ```text
   https://github.com/Mordevolt/ha-syslog-server
   ```
5. Нажмите **Добавить**, затем обновите страницу магазина.
6. В списке дополнений появится **Syslog Server**. Нажмите на него, затем нажмите кнопку **Установить**.
7. Включите переключатель **Показывать на боковой панели** и нажмите **Запустить**!

## 📡 Настройка роутера

Укажите в веб-интерфейсе вашего роутера IP-адрес сервера Home Assistant и стандартный UDP-порт `514`.

| Роутер | Где настраивается |
| :--- | :--- |
| **Keenetic** | *Управление* -> *Журнал* -> *Отправлять на сервер Syslog* -> IP Home Assistant, порт 514 |
| **MikroTik** | *System* -> *Logging* -> Добавить Action `remote` (IP Home Assistant, UDP 514) и привязать в Rules |
| **OpenWrt** | *System* -> *System* -> *Logging* -> Внешний сервер Syslog (IP Home Assistant, порт 514) |
| **Asus / TP-Link** | *Администрирование* / *Системный журнал* -> *Удаленный сервер журналов* |

---

## 🛠️ Параметры конфигурации

Настраиваются в графическом виде во вкладке **Конфигурация**:

```yaml
syslog_port: 514          # UDP порт сервера логов
retention_days: 14        # Срок хранения логов в днях
max_db_size_mb: 500       # Максимальный размер файла базы (МБ)
rate_limit_per_sec: 100   # Лимит пакетов в секунду на один IP
allowed_hosts: []         # Список разрешенных IP (например: ["192.168.1.1", "192.168.1.0/24"])
```
